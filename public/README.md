# GODIA PRIME CONNECT — Public Assets

This folder contains public files used by the GODIA PRIME CONNECT application.

## Files

- `manifest.webmanifest` — Progressive Web App name and display settings.
- `godia-prime-icon.svg` — GODIA PRIME CONNECT application icon.

## Important

These files must be served correctly by the existing Cloudflare Worker before the app can use them.

Do not delete or replace existing application files or databases.
